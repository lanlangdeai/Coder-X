## 使用

### 常用命令

| 命令                                                         | 说明               |
| ------------------------------------------------------------ | ------------------ |
| php artisan config:clear                                     | 清理配置缓存       |
| php artisan  make:command Api\SyncAiModelConfig              | 创建命令脚本       |
| php artisan queue:work --queue=队列名称                      | 启动某个队列       |
| php artisan make:event TaskStatEvent<br/>php artisan make:listener TaskStatListener --event=TaskStatEvent | 创建事件以及监听器 |
