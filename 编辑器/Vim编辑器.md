# Vim编辑器



## 配置

> 配置文件: /etc/vimrc





## 使用

| 命令           | 说明                      |
| -------------- | ------------------------- |
| dG             | 从当前行删除到末尾        |
| dd             | 删除当前行                |
|                |                           |
|                |                           |
|                |                           |
|                |                           |
|                |                           |
|                |                           |
| :10,20s/^/#/g  | 在 10 - 20 行添加 # 注释  |
| :10,20s/#//g   | 在 10 - 20 行删除 # 注释  |
| :10,20s#^#//#g | 在 10 - 20 行添加 // 注释 |
| :10,20s#^//##g | 在 10 - 20 行删除 // 注释 |
